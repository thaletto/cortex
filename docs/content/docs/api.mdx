## VectorDB Service

The primary service for interacting with vector collections.

### Methods

| Method | Params | Returns |
| ----| -- | -- |
| `upsert` | `UpsertPayload` | `Effect< CollectionSchema, ... >` |
| `upsertMany` | `UpsertPayload[]` | `Effect< CollectionSchema[], ... >` |
| `search` | `Vector, limit, QueryFilter?` | `Effect< SearchResult[], ... >` |
| `getById` | `DocumentId` | `Effect< CollectionSchema, ... >` |
| `findById` | `DocumentId` | `Effect< Option< CollectionSchema >, ... >` |
| `delete` | `DocumentId` | `Effect< void, ... >` |
| `list` | `QueryFilter?, Pagination?` | `Effect< CollectionSchema[], ... >` |
| `count` | `QueryFilter?` | `Effect< number, ... >` |
| `pruneExpired`| `Date` | `Effect< number, ... >` |

## Types

### `UpsertPayload`
```typescript
{
  id: DocumentId
  content: string
  category: string
  tags: string          // Note: Single string in payload, becomes string[] in DB
  metadata_json: string
  vector: Vector
  expires_at: Date
}
```

### `SearchResult`
```typescript
{
  document: CollectionSchema
  score: number         // 0 to 1 (higher is more similar)
}
```

### `QueryFilter`
```typescript
{
  category?: string
  tags?: string[]
  activeAt?: Date
}
```

## Errors

- `VectorDBError`: `{ message: string, cause?: unknown }`
- `DocumentNotFound`: `{ id: DocumentId }`
- `DimensionMismatch`: `{ expected: number, actual: number }`
