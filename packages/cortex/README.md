# @thaletto/cortex

Cortex is a type-safe ORM (Object-Relational Mapper) for Vector Databases, designed to simplify working with vector embeddings, collections, and search operations.

## Features

- **Type-safe:** Built with TypeScript for reliable vector operations.
- **ORM for Vectors:** Define collections and vectors as typed entities.
- **Composable:** Easily swap or extend vector database backends.

## Installation

```bash
npm install @thaletto/cortex
```
