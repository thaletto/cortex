# @thaletto/zvec

ZVec adapter for [@thaletto/cortex](https://github.com/thaletto/cortex).

## Installation

```bash
npm install @thaletto/zvec
```

## Usage

This package provides a ZVec implementation for the Cortex vector database ORM. It enables seamless integration between Cortex and ZVec-compliant vector stores.

For more information, see the [Cortex documentation](https://cortex-vector.vercel.app).
